## Development

This version runs as a frontend-only React demo. Authentication, scan history, and the sample analysis result use browser `localStorage`; no Supabase, AI API, or backend credentials are required.

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
